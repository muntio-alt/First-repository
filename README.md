# 👚 내 옷장 (My Wardrobe)

집에 있는 옷을 사진으로 등록해서 한눈에 보고, 아바타에 입혀보며 코디를 만들어 저장하는 웹앱입니다.
설치나 빌드 없이 브라우저에서 바로 동작하고, 휴대폰 홈 화면에 추가하면 앱처럼 쓸 수 있어요.

## 주요 기능

| 탭 | 기능 |
|---|---|
| **옷장** | 사진 찍기/앨범 선택으로 옷 등록 · **배경 자동 제거** · 종류(상의/하의/원피스/아우터/신발/가방/모자/액세서리) · 색상 · 계절 · 브랜드 · 메모 · 검색과 필터 |
| **피팅룸** | 아바타에 옷 입히기 · 드래그로 위치 맞추기 · 크기/회전 조정 · 🎲 계절에 맞는 랜덤 코디 · 코디 저장 |
| **코디북** | 저장한 코디 모아보기 · 다시 입혀보기 · "오늘 입음" 기록(옷별 착용 횟수/마지막 착용일) |
| **설정** | 아바타 피부색·헤어·머리색·체형 · 옷장 통계 · 백업 내보내기/불러오기 |

## 사용 방법

### 1) 바로 써보기 (GitHub Pages — 추천)
1. GitHub 저장소 → **Settings → Pages**
2. Source: `Deploy from a branch`, 브랜치 선택, 폴더 `/ (root)` → Save
3. 잠시 후 나오는 주소(`https://<아이디>.github.io/<저장소>/`)를 휴대폰에서 열기
4. 공유 버튼 → **홈 화면에 추가** (iPhone Safari) / 메뉴 → **앱 설치** (Android Chrome)

### 2) 내 컴퓨터에서 실행
```bash
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

## 사진 잘 찍는 팁
- 옷을 **단색 벽이나 바닥, 침대 시트 위**에 펼쳐놓고 위에서 찍으면 배경이 깔끔하게 지워져요.
- 배경이 덜 지워지면 등록 화면의 **지우는 정도** 슬라이더를 올려 보세요. 옷까지 지워지면 내리면 돼요.
- 피팅룸에서 옷을 탭하면 선택되고, 끌어서 위치를, 슬라이더로 크기와 회전을 맞출 수 있어요.

## 데이터 저장
- 모든 사진과 코디는 **이 기기 브라우저(IndexedDB)에만** 저장되며 어떤 서버로도 전송되지 않아요.
- 폰을 바꾸거나 브라우저 데이터를 지우기 전에 **설정 → 백업 내보내기**로 파일을 저장해 두세요.

## 파일 구성
```
index.html            화면 뼈대
styles.css            디자인
app.js                앱 로직 (옷장, 배경 제거, 아바타, 코디, 백업)
sw.js                 오프라인 실행용 서비스 워커
manifest.webmanifest  홈 화면 설치 정보
icon.svg              앱 아이콘
```
